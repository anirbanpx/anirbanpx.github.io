## Stack

Plain HTML, CSS, and JavaScript — no framework, no build step. Deployed via GitHub Pages.

```
index.html      # all content
css/style.css   # design system + layout
js/main.js      # scroll animations, nav behaviour
assets/         # images, CV PDF
```

---

## Running locally

```bash
# Any static server works, e.g.:
npx serve .
# or
python -m http.server 8000
```

Then open `http://localhost:8000`.
